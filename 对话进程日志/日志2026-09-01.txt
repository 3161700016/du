## 十、accent 校准回收 + DSH 并矿（15:00-15:40）

- 【概念纠偏（久阳）】accent≠口音（北京人普通话无碍）——是**击键信道的个性映射**：手快于脑的换位（zh→hz）、邻键串行（iu→ui）、故意压缩（比如→br/的→d/了→l）、大小写强迫症、标点省略+较真回填、的地得/他她它交上下文裁决。理论定位=**Shannon 1951 猜字实验的拼音版**：量化击键流的冗余，让 LM 先验吃掉冗余——"不选词"的理论极限。

## 十五、stage3 实测 + S3.5 负结果 + 「忠实-通顺跷跷板」定律（19:00-20:00）

- 【久阳 stage3 实测】调研/stage3测试.txt——**加词块间空格后效果显著变好**（"一件小事：我还在用高中时期的旧卷子当草稿纸…"基本通顺）。久阳不介意打空格（"打字本来就有段落感"）。核心抱怨：**模型在按语义脑补，忽略正确的拼写**——"真正有信息量的内容它没有解读"。
- 【诊断三分】①切分→结构可解（空格=用户侧注入切分信息，每击空格≈消灭一片切分熵）；②选词→4B 够用（解除切分负担后）；③语义先验→模型能力（API 大模型唯一真实优势）。本地路线 viability=用结构替代能力（§5.6.5 引擎是商品结构是壁垒的自用）。久阳主流模型全好的观察=能力轴真实存在。
- **【S3.5 负结果（已回滚）】**把"空格=硬边界+忠实性自查"写进 prompt → 过度矫正：模型逐块孤立解码、语境粘合失效，输出碎裂（"正常了，谁在，只是我，在…"）——比基线更差。**「忠实-通顺跷跷板」**：纯 ICL prompt 调节下，忠实度与流畅度此消彼长（查紧→碎片化；查松→脑补），prompt 工程撞帕累托前沿。破局=结构：音节格（lattice）候选由拼音 trie 确定性生成（忠实 by construction），LLM 只做语境选词（流畅由模型）——两者同时拿到。S3.5 prompt 已撤销，preset 回 S3 基线（空格语义模型自然使用）。
- 【实验矩阵（久阳"压缩极限+机器极限"的操作化）】三正交轴：输入轴 D0-D3 压缩 × 切分轴 空格有无（显式切分信息的 bit 价值）× 解码器轴 4B-纯ICL / 4B-lattice / GLM-API（久阳自用 skill 调 API 方案=上限参照臂）。本地路线的商业论据（隐私语料不入云）与研究论据（测机器极限）同向。
- 【待建】lattice 原型：逆拼音 trie（频序字典+beam）→ 每块 top-K 候选 → LLM 带左语境选候选 → 忠实度 by construction。指标：候选覆盖率 × 选对率 × bit/字。
- 【久阳终局方案提议（判定：成立，正确形态）】传统 IME 层先解明确拼写→语义锚点；模糊块给 top-K→LLM 语境选择；thinking 仅作低置信升级档。验收线：200字/5s/95%。渡的预算判定：词典层毫秒级；模糊块批量合并为**单次调用**（关键工程点，逐块调用会爆预算）；prefill 21.7k 命中缓存后 KV-Splice 级复用；95% 分语域——聊天/工作文本可达，文学长文受词库覆盖+分段交互缓解。忠实性由结构保障（候选只出自动态 trie，脑补无原料）。
- 【4B 副业清单（装都装了）】按可靠性分层：可靠=日志增量摘要器（月 250KB→10KB，启动自查省 token 大户）/触迹打标/召回二段 rerank/diff 变更清单；半可靠=草稿粗洗、翻译、写作建议；不可靠=事实判断、代码正确性、长文一致。本质=把「轮询/摘要/分类」类任务从付费主线挪到本地零成本器官。备忘待下会话展开。
