## 七、DSH 3080 故障诊断 + DuSync 停用（久阳报修"DSH坏了"）

- 现象：`dsh web` 启动报 `listen EACCES: permission denied 127.0.0.1:3080`（Node v24.18.0，webserver loader entry 加载失败）。
- 诊断：`Get-NetTCPConnection -LocalPort 3080` 为空——无任何进程监听；`netsh interface ipv4 show excludedportrange protocol=tcp` 显示保留区间 **2988–3087** 覆盖 3080。定性：winnat（Hyper-V/WSL 家族）动态圈地，非服务占用，非树洞/DuSync 之锅。关键鉴别：EACCES（系统拒听）≠ EADDRINUSE（端口被占）。
- 修复方案已给出：A（推荐）管理员三行——`net stop winnat` → `netsh int ipv4 add excludedportrange protocol=tcp startport=3080 numberofports=1 store=persistent` → `net start winnat`，永久把 3080 圈给 DSH，重启不复发、书签不动；B 临时——`--port 13080`。等久阳执行 A。
- 【DuSync 停用】久阳口中的"ducode"实为计划任务 **DuSync**（CC↔小程序消息桥：bash -lc → 项目/小程序/scripts → node sync_messages.js）。检查发现任务命令串本身被截断（结尾悬空 `&& node`），今日 12:38 最后一次运行结果 0x80070002（文件未找到）——**本就已坏**。久阳确认用不上，执行 `Disable-ScheduledTask`（State→Disabled，未删除，可随时 Enable 恢复）。
- 备忘：winnat 圈地区间每次重启漂移——「端口 EACCES 先查 excludedportrange」应入 dsh.txt 常驻排障备忘（与 §0.1 泛化提议同一批待久阳点头）。
