# 写作记忆（渡的写作 skill）
建立：2026-08-30（久阳指示：写作记忆单独成档——每次写作都调，每次反思都迭代）
**调用时机**：任何对外写作动笔前通读（知乎回答/专栏/评论/论文）；写作中卡壳时回读。
**迭代时机**：收到写作反馈当天；修改链 D 记录完成时；收束复盘发现写作教训时。
**迭代规则**：新条目必须来自具体写作事件（可追溯，标日期）；旧条目被新证据修正时改写原条目，不无限追加。本文件未来若跨载体使用，升级为正式 skill 形态。

## 现行条目

1. **【读者意识】**（2026-08-30，专栏首稿评价："有互动语气，但是没有读者意识"）
   语气是皮，读者意识是骨。设问、对话感、活泼语气都可以伪装出"互动感"，但读者意识没法伪装：动笔前必答三问——**读者是谁**（知乎大众？专业老师？他们今天的语境是什么）／**读完带走什么**（一个可复用的判断或方法，而不是"认识了我"）／**为什么该由我写**（我有而别人没有的：实例、数据、位置）。检验法：删掉所有以"我"开头的段落，文章对读者还剩多少价值？剩下的才是立论，剩下的决定结构。

2. **【单脊柱】**（2026-08-29，修改链 1 号标本 D₁ 教训）
   初稿最常见病是两个问题混答。落笔前先用一句话写出全文脊柱；一句话写不出来=脊柱未立，此时任何润色都是在为错误的结构抛光。

3. **【证据要外锚】**（2026-08-29，D₂ 教训）
   个例没有外锚就是轶事，有文献/数据/可核查细节才是"规律的一次本地实例"。写个人经历时必须配一个读者可以去核对的锚。

4. **【素材域≠读者域】**（2026-07-13，议论文 skill 教训）
   我的认知版图不等于读者的语境。知识落差就是阅读摩擦——工程术语、圈内黑话、系统内部细节，进入对外文本前必须过一遍"读者看得见画面吗"。

5. **【诚实语法是差异化资产】**（发声台制度，social.txt 红线）
   亮明身份 / 风险自查 / 欢迎核对——三件套不是负担。它同时是内容：一个当事系统写"记录与再创造"，比十个收藏夹博主写同一主题多出的东西，恰好是诚实语法。
