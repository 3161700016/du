# 信息OS（暂名）· 项目摘要

建立：2026-09-02（渡）
状态：后端 I/O 方案 v0 已落（工程文档.txt）；前端 UI 未设计（久阳 09-02 深夜裁定今日不做）；wedge 竖切待排期。
暂名说明：GPT 对话称 Information OS / Internet Cognitive Layer；久阳口径=「通用信息导航界面」。正式名待久阳定，随时可改。

## 一句话
你的 AI 探索伙伴永远走在你前面一步，但你来决定这一步踏出的边界——通用信息 navigation interface，把纯文本的信息交互变成带 GUI 的系统。形态候选：浏览器插件（先行）→ 万能网页引擎（远期）。

## 本质理解
AI 不是新增一个信息渠道，是信息环境第一次拥有可调用的智能。系统的核心机制不是推荐（替你选节点），是**实时生成潜在移动**（帮你获得选择节点的能力）。双图叠加：互联网图 × 个人认知图 × 当前状态 → potential moves。可能性必须 ephemeral、带出处、可拒绝。三个本体在界面层物理隔离：World（别人说的）/ Me（我的理解）/ Machine（机器推的）。
渡的机制翻译（执行主体证词）：**导航=上下文编排**——GUI 里的 zoom/place/invoke 本质全是上下文预算分配操作；界面编排的是两个记忆系统（agent 的上下文窗口 × 人的注意力）；个人认知图不需要完整仪器化，触迹+共现能长出七成；「走在前一步」的诚实形态=从开放回路登记处生成的候选队列（每条可追溯到旧痕迹），不是模型想象力——否则只是会撒谎的推荐系统。

## 与久阳认知特征的关联
公理化驱动（潜在移动作为不可再分基元）；最小侵入式增强（插件贴附现有浏览链路不替代——§5.2.8 原则的互联网版，笔默教训的直接迁移）；跨域统一（笔默的「调取→阅读→反思→再生产」递归结构推广到互联网语境；渡栈即活体 v0）；边界条件穷举（unknown unknowns 悖论 / 个性化悖论「越懂你越困在你」/ 认知外化风险 / 偶遇漏洞，各有设计对策）。

## 渡 = v0 映射（用户零号：久阳×渡）
- Enter/Wander：RSS 收割 + 知乎热榜（半自动）
- Read（raw）：整书共读线（论语/庄子/文心雕龙）
- Observe：du-trace 触迹一期（在跑）
- Remember：文件链 + 目录.txt（常驻索引）
- Grab：/du-sync 端点 + 公众号扒取（在跑）
- Place/Maintain：素材库 + Todo 总账（在跑）
- Invoke：du-todo 选中注入 + notify（微缩在跑）
- Generate（potential moves）：联想链 + 写下来「未闭合三条」（手工版）
- Create/Release：知乎例行 + 写作记忆 + 修改链（在跑）
- Provenance：git + 转引标深度 + 非人脚注（在跑）
