# 项目/浏览器插件/爬取工具/

建立：2026-08-27（渡）
定位：把网页结构降维成工作区文件的**浏览器侧工具**——渡借久阳的浏览器获得的手与眼。

## 家族与边界

- 本目录 = **内容爬取**（网页原文/清单 → 工作区文本）
- ../网页chatbot/ = **对话同步**（其它 AI 的对话 → context备份）
- 共同依赖：DSH 运行中 + dusync-1 动态插件提供的 POST /du-scan 端点存活。
  探测方法：浏览器或 curl GET http://127.0.0.1:3080/du-scan 应返回 405 JSON（而非 GUI 页面）。

## 脚本清单

| 脚本 | 版本 | 目标页 | 功能 |
|------|------|--------|------|
| gushiwen.user.js | v0.4 | 古文岛章节页 | 单章抓取，标题自动推导＋全程诊断回显 |
| 公众号合集扒取.user.js | v1.0.2 | 微信合集页 (appmsgalbum) | 纯JSON收割清单 + 纯树遍历正文提取 + 批量归档 |

## 使用流（通用）

1. Tampermonkey 新建脚本 → 粘贴对应 .user.js 全文 → 保存
2. 打开目标页面（合集页/章节页）
3. 点浮动按钮 → 按提示确认归档名 → 等待完成弹窗
4. 回报 DSH 对话框，渡核验文件并入库

## 设计原则

- **人触发**：一切由久阳在页面上点按钮启动，默认不自动运行（dsh.txt 默认关闭项一致）
- **结构优先**：一次收割结构化清单（00-合集清单.txt / 00-manifest.json），之后的精读走本地检索——重要的不是查信息，是查结构化的信息（久阳，2026-08-27）
- **断点续传**：du-scan 端点的 createIfAbsent 防覆盖使重复执行天然安全——已存在文件被拒写=跳过
- **诊断回显**：失败必带原因（标题源/h1候选/错误体），不留无声黑盒

## 协议情报（2026-08-27 实测，维护用）

合集翻页（同源 fetch 即可，无需 GM）：
```
GET /mp/appmsgalbum?action=getalbum&__biz=<biz>&album_id=<id>
    &count=20&begin_msgid=<上批末msgid>&begin_itemidx=<上批末itemidx>&is_reverse=0&f=json
→ getalbum_resp.article_list[]；单批~20条；空游标(0,0)从头取
```
条目字段：msgid / itemidx / title / url / create_time(秒) / item_show_type(0=图文)

⚠ 数据源纪律（v1.0.1 教训，复杂科学前沿2026 合集实证）：**只信 f=json，不信列表 DOM。**
合集页首屏部分 `<li>` 的标题/时间属性未渲染完全即存在于 DOM，v1.0.0 曾因此产出 40/157 条
空标题；纯 JSON 游标全程走完则 157 条全带完整字段（9 轮收敛）。索引文件无法被端点覆盖
（防覆盖策略），需重制索引时由渡在工作区直接重建。

列表 DOM 结构仅作参考：<li class="album__list-item" data-msgid data-itemidx data-link>
文章页正文容器 #js_content；标题 #activity-name 或 og:title；公众号 #js_name；时间 #publish_time

⚠ 正文提取纪律（v1.0.2 教训，复杂科学前沿2026 前18篇实证）：**只用 DOM 树遍历取 text 节点，
不用 innerText / 隐藏盒方案。**克隆节点携带源页内联样式（微信对 js_content 的可见性开关），
渲染计算会让部分子树隐形——产出只剩导语的 1-2KB 残篇。树遍历不经过布局引擎：
text 节点直取、块级标签出换行、script/style/svg 跳过、IMG 记 [图] 占位。
完成弹窗含「短文(<300字)计数」作为提取质量哨兵；单条诊断看文件头元信息＋console [du-album]。
