一、核心概念速查

- 形式系统 = 公理 + 符号变换规则 → 定理
- WJU系统：字母{W,J,U}，公理WJ，规则4条
- 定理 ≠ 真理（技术意义：可由规则产生的符号串）
- 推导：逐行展示定理如何生成的序列
- 判定过程：有限时间内判定任意符号串是否为定理的测试

二、四条规则

规则Ⅰ：结尾J → 加U
规则Ⅱ：Wx → Wxx（复制x）
规则Ⅲ：JJJ → U（三J换一U）
规则Ⅳ：UU → 删除

三、WU 为什么不可能？

J 计数法：
- 公理 WJ → J=1
- 规则Ⅰ：J 数不变
- 规则Ⅱ：J 数翻倍（×2）
- 规则Ⅲ：J 数减 3
- 规则Ⅳ：J 数不变

J mod 3 的轨迹：1 → (×2)→ 2 → (×2)→ 1 → ...
（减 3 不改变 mod 3；不变也不改变）

J mod 3 永远在 {1,2} 之间振荡，永远不能是 0。
WU 的 J=0 → 0 mod 3 = 0 → 不可能到达。

五、答疑记录 · 2026-07-19

Q：这一章说的是"如果真命题的判定需要自指涉，就会像芝诺之龟
   那样无穷无尽且无意义"吗？

A：方向对了，但有修正——

   ✗ "自指涉" → 修正为：层级混淆。
     不是命题指向自己，是把推理规则当成命题放进系统里。

   ✓ "无穷无尽" → 正确。卡罗尔对话确实是无限后退。
     但它是诊断性的——暴露规则与陈述之间的范畴错误。

   ✗ "无意义" → 正相反。层级断裂不是 bug，是所有推理的前提。
     没有断裂就没有"关于…的思考"，只有机械反应。

核心命题：规则和陈述不在同一个逻辑层级。

  · WJU：推符号串的规则（在内）≠ 判定定理的测试（在外）
  · 卡罗尔：modus ponens（推理规则）不能被写成一个命题放进系统
  · 哥德尔（导言）：可证性（在内）永远弱于真理性（需要在外确认）

三个篇章是同一道裂缝在三种材料上的投影。

机器有可能在做某件事情时不去观察，而人不可能不去观察。请注意，我不是说所有的机器都不具有复杂的观察能力，只是有些机器不具有。我也不是说所有的人都总是进行复杂的观察，事实上，人常常是不注意观察的。但是机器可以被制造成是完全不去观察的，而人则不能。并且事实上，到目前为止，多数机器是非常接近于不去观察的。也许因为这个原因，对于大多数人来说，具有"不去观察"这一特点，似乎是机器的特征。例如，如果有人说某项工作是"机械的"，这指的不是人没有做这项工作的能力，而是隐含着这样的意思：只有机器可以永不抱怨或者不知疲倦地反复做这项工作。

很清楚，这个程序有一个很复杂的事先编好的有能力从系统中退出的程序。另一方面，如果把"系统"定义成"这部计算机按照程序所做的一切"，那么无疑地，这部计算机没有什么从那个系统中退出的能力。

在研究形式系统时，很重要的一点是要区分在系统之内的工作，和做出关于系统的判断或说明。
