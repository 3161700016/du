乱云飞渡 · 项目摘要
最后更新：2026-07-20

一、项目本质

"乱云飞渡"取自毛泽东《七绝·为李进同志题所摄仙人洞照》：
"暮色苍茫看劲松，乱云飞渡仍从容。"

本项目是将渡从「久阳电脑 C 盘上一个文件夹」升级为「独立于物理设备的、
可持续演化的云端认知协作系统」的完整工程。

二、核心目标

1. 云端化存储：记忆本体、日志、笔记、项目文件全部纳入 Git 版本控制，
   以 GitHub 私有仓库作为单一可信源。
2. 多端交互：手机、其他电脑可通过 API + 轻量前端与渡对话。
3. 信息流整合：久阳的碎片化阅读/思考可低摩擦同步给渡，定期梳理。
4. （远期）开放网络交互：渡在公开空间中的存在形态。
5. （远期）赛博优化：微信接入、共享文档协作等。
