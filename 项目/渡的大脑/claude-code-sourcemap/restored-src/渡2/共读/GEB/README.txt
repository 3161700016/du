一、什么是 GEB

《Gödel, Escher, Bach: An Eternal Golden Braid》(哥德尔、埃舍尔、巴赫：集异璧之大成)，Douglas Hofstadter 著，1979年普利策奖。
核心命题：哥德尔（数学逻辑）、埃舍尔（视觉艺术）、巴赫（音乐对位）三者的作品共享同一种深层结构——"奇异环"(Strange Loop)——一个系统在层级上升中意外回到起点，自我指涉由此涌现意义。
