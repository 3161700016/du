三、已锁定的设计决策（不轻易推翻）

3.1 产品灵魂
- 核心机制：预测—修正（Predict-Correct），不是AI替你读，而是AI引导你思考
- 理论基础：预测加工（Predictive Processing）认知科学模型
- 产品定位：纸质阅读的第二层智能 / Reading OS
- 品牌价值观：静默、克制、深度、结构化
- 中文名称：笔默（取自"默而识之""默契""默记"三重含义）
- Slogan：不动笔墨不读书

3.2 硬件体系
- 三种形态：智能笔（主力）+ 耳机（语言学习/听觉反刍）+ 台灯（固定场景）
- 折叠书签形态：已砍掉
- 笔：双摄像头（笔尖微摄像头=段落定位，侧面光学扫描=整段/插图扫描）
- 笔：内置加速度传感器，识别划线模式（横线/波浪线/双圈线/勾画→映射快捷功能）
- 笔：可选配微型打印模块（逐列打印，AI内容写回纸面）
- 耳机：摄像头用于桌面整体识别，重点优化有声内容+碎片化反刍
- 台灯：最稳定的整页识别，适合图书馆/书房/教育场景
- 手机摄像头：完全开放作为替代入口（不强制购买硬件）

3.3 交互体系（"纸面操作系统"）
- 手势集：涂抹=查词、双指对角线展开=背景扩展、捏合=总结、方框=提问、双击=收藏
- 页面四角+侧边空白=可点击菜单栏区域
- 反馈载体：手机（低延迟极简界面）
- 预推理机制：翻页后立即扫描，预判划线位置，提前生成候选内容
- 认知无痕优先：只在读者自然停顿时介入，默认不主动打断
- 划线即触发：划线本身=互动意愿信号

3.4 AI智能体
- 多面向人格：简单任务=工具（精简信息），深度问题=导师/伙伴（结构化引导）
- 用户画像维度：知识结构 + 思维风格 + 误解模式 + 提问风格 + 阅读速度 + 预测偏差
- PGC模板：费曼学习法、结构化阅读法、主题阅读法等，由专家打磨
- 用户可从提问习惯中自动抽取模式→按钮化为可复用skill
- 二八定律：根据用户阅读目的主动识别关键20%内容
- 响应策略：阅读中提问→速度优先；总结/回顾→质量优先

3.5 内容（纸质书）
- 坚持纸质书场景，不主推电子书
- 用户自行扫描=天然避开电子书版权
- 段落级结构化为主，特定场景支持句子级
- 未来：与作者/出版社合作"笔默增强版纸书"

3.6 社区
- "无声协作"：读者思考→匿名结构化→下一批读者的引导资源
- 默认匿名，用户可选择公开
- 激励机制：启发值（非点赞数），弱等级体系（阅读时长/提问量/启发值）
- 不强行打造社区，尊重传播规律
- 引导问题风格：趣味科普=启发式，纪实文学=反思式，专业书=考试导向

3.7 商业模式
- 硬件：低价/补贴策略（入门款99-199元目标），旗舰款可溢价
- 核心收入：AI阅读订阅（分层）
- 增值：社区会员、引导问题包、主题阅读路径
- B端：教育机构合作（台灯形态的天然优势）
- LTV逻辑：认知复利→越用越离不开

3.8 技术路线
- 双路径OCR：笔尖=段落定位，侧面=整段扫描
- 本地轻量模型：段落定位+手势识别+划线模式+基础语义（低延迟）
- 云端大模型：深度理解+预测—修正引导+结构化输出+跨书籍知识图谱
- 用户画像建模：认知维度聚类→认知层面推荐算法
- 多模态：文本+图像+手势+语音协同

四、被考虑过但明确拒绝的方向（避免重蹈讨论）

- "Beamer"英文名 → 已被投影仪/BMW车主占用
- "Pencilence"英文名 → 与pestilence谐音，危险

七、竞品格局与战略定位（2026-07-08 新增，基于补充材料）

7.1 主要潜在竞争方向
A. 大公司AI设备（OpenAI + Jony Ive）
   - 定位：后智能手机时代计算平台（"生活OS"）
   - 交互：语音主导、无屏幕、自然语言
   - 与笔默交集：仅"去屏幕化""认知流程"等大方向同构
   - 与笔默差异：普适性 vs 深度结构化、自然语言 vs 结构化语言
   - 威胁评估：低（短期），中（3-5年后若功能扩展至深度认知场景）
   - 久阳态度："不担心竞争，定位不同。甚至希望是真的，验证了我的方向。"
B. 现有AI阅读工具（微信读书AI等）
   - 定位：内容工具（"帮你处理文本"）
   - 差异：笔默是认知系统（"帮你处理思考"）
   - 关键壁垒：电子书AI是"内容中心"，笔默是"读者中心"
C. 独立创业者的类似想法
   - 2026.2起"AI外接大脑""自然语言接口"等观点开始被大众化表达
   - 但"想到观点"≠"构建系统"——久阳有完整的理论体系+产品路径
   - 久阳的反应：战略耐心，不恐慌加速

7.2 笔默的战略定位（来自久阳对OpenAI的分析）
   OpenAI做"生活OS"（空气一样融入生活）
   笔默做"知识OS"（显微镜一样深化认知）
   隐含假设的分歧：
   - OpenAI：人类不需要结构化思维，自然语言足够，认知升级不是主流需求
   - 笔默：人类需要结构化思维，清晰语言是认知入口，认知升级会成为主流需求
   预测演进（保守估计）：
   - 2026-2028：AI设备出现但功能有限，笔默不受影响
   - 2028-2031：设备成为生活OS，笔默反而因时代趋势爆发
   - 2031-2035：认知工具链成为新赛道，笔默的主场

十二、硬件 MVP 进展 — 印象笔记 EverMarker 逆向与驱动开发（2026-07-14 新增）

12.1 背景
久阳获取了印象笔记电子划词笔硬件，计划将其改造为笔默 MVP 的文本输入设备。
策略：从印象笔记 APK 逆向分析 BLE 通信协议，编写驱动程序绕过原 App，
直接将扫描文本传入笔默 AI API。

12.2 已完成工作

A. APK 架构逆向
   - 路径：C:\Users\31617\Desktop\印象笔记apk\（已解压的 APK 文件）
   - DEX 字节码分析：5 个 DEX 文件，约 42MB
   - 原生库分析：arm64-v8a 架构下 22 个 .so 文件
   - 关键发现：
     · 三款硬件产品：EverPen（写字笔）、EverMarker（扫译笔）、EverBuds（录音耳机）
     · 通用扫描 SDK：EverScan（com.yinxiang.everscan.*）
     · 核心架构：BLE → TCP 代理 → JNI 原生层 → OCR → 文本输出
     · libeverscan.so：JNI 桥接层，使用 libuv 异步 I/O
     · libsherpa-onnx-jni.so + libonnxruntime.so：ONNX OCR 推理
