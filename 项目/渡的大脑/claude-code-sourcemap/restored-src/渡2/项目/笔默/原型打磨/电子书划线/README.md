# 电子书划线监控

笔默阅读工作流的一部分。后台监控剪切板，每次 Ctrl+C 划线自动追加到对应章节的速记本。

## 快速开始

```bash
cd "C:\Users\31617\Desktop\渡\项目\笔默\原型打磨\电子书划线"
python clipboard_monitor.py <书> <章号> [章标题]
```

## 示例

```bash
# GEB 第一章
python clipboard_monitor.py GEB 1 "WU谜题·形式系统"

# GEB 第二章（自动检测章节切换，创建新速记本）
python clipboard_monitor.py GEB 2

# 论语
python clipboard_monitor.py 论语 学而
```

## 工作流

```
┌─────────────┐     ┌──────────────┐     ┌──────────────────┐
│ 阅读器里读   │ ──→ │ Ctrl+C 划线  │ ──→ │ 自动追加到速记本  │
│ 纸质书/PDF  │     │ （剪切板）    │     │ 共读文档/         │
└─────────────┘     └──────────────┘     └──────────────────┘
                                                 │
                                                 ↓
                                          ┌──────────────────┐
                                          │ 读完后渡分析讨论  │
                                          │ 填充核心概念+答疑 │
                                          └──────────────────┘
```

## 章节切换

每次启动时，脚本会检测章节是否变化：

- **同一章节** → 续写已有速记本，划线追加到末尾
- **切换章节** → 自动创建新速记本（含模板头），旧速记本保留不动
- **首次启动** → 创建速记本 + 开始监控

切换检测通过 `.last_chapter.txt` 记录上次的 `<书>第<章>章` 标识。

## 速记本格式

新建的速记本包含标准模板：

```
<书> 第<章>章 · 速记本
━━━━━━━━━━━━━━━━━━━━━━

创建：<时间戳>
章节：<书>第<章>章 · <章标题>
状态：共读进行中

━━━━━━━━━━━━━━━━━━━━━━

一、核心概念速查

（共读讨论后由渡填写）

二、划线记录

<这里开始追加 Ctrl+C 的划线>
```

模板头由脚本自动生成，**核心概念速查**部分在共读讨论后由渡手动或通过 Edit 填入。

## 停止

- `Ctrl+C` 优雅停止，显示本次划线统计
- 直接关闭终端窗口也可以

## 注意事项

- 相同内容连续 Ctrl+C 两次只记录一次（去重）
- 输出使用 UTF-8 编码
- 仅支持 Windows（使用 Win32 Clipboard API）
- 如果要在 macOS/Linux 上使用，需替换剪切板读取实现
