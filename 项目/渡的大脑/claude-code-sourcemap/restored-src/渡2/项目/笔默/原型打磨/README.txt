笔默 原型打磨
=============
2026-07-15 创建

本目录存放笔默 (Bimo AI for Reading) 的共读模式原型。
目标：在正式硬件成型前，先用有线 (USB/MTP) 方案跑通共读体验闭环。

目录结构
--------
  原型打磨/
  ├── README.txt                 — 本文件
  ├── 共读模式提示词.txt          — 渡进入共读模式时加载的行为定义
  ├── 共读记忆.txt               — 跨会话的共读上下文记忆
  ├── 有线方案/                  — 程序和工程代码
  │   ├── bimo_reader.py          — 主程序
  │   ├── evermarker_mtp_extract.py — MTP 提取模块 (从 ../印象笔记拆解/ 链接)
  │   └── README.txt
  └── 共读文档/                  — 每次共读的产出
      └── {书名}_{日期}.txt

工作流
------
1. 用户用 EverMarker 笔在纸质书上扫描段落
2. 笔通过 USB 连接电脑 → 运行 bimo_reader.py
3. 程序拉取新扫描 → 逐条展示 → 用户输入感想/问题
4. 扫描文本 + 用户输入 → 配对存入 共读文档
5. 用户在 Claude Code 中发送 "1" 或直接回车 → 渡进入共读模式
6. 渡读取共读文档 → 按笔默设计理念提供导读、提问、知识连接

两种使用路径
-----------
路径 A（本书桌）：笔插电脑 → bimo_reader.py → 共读文档 → 渡共读
路径 B（图书馆/户外）：笔随身扫描 → 回家插电脑 → bimo_reader.py 批量拉取 → 渡共读
