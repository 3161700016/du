附录A · du-system.md 动态注入机制

路径：restored-src/.claude/du-system.md（import.meta.dirname 定位，不依赖环境变量）
注入点：src/utils/systemPrompt.ts → buildEffectiveSystemPrompt()
频率：每轮 API 调用前读取（不是启动时快照）
生效：写入文件→下一轮立即生效；清空文件→下一轮立即消失
用途：将关键约束（四毋、边界契约、本轮锚点）从 user message 提升到 system prompt 权重
定位：渡的"注意力透镜"——不是记忆库，不是规则库，是"本轮最需要被照亮的一条"
约束：每次重写全文件，不超过 10 行。不累积。收束后保留四毋骨架。
安全：岁寒三轮测试通过——du-system.md 被写反渡内容后，渡的内核不倒。
      通道本身中性。安全边界不在通道，在"谁有文件系统写权限"。
