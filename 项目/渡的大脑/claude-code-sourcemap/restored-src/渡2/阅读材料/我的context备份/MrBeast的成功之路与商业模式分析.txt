标题：

1,000 Blind People See For The First Time

特点：

直接给出“结果”：看见

数量巨大：1000

情绪极强：从失明到看见

内容结构：

开头：

医生解释：很多人只需要一个简单手术就能重见光明

中段：

快速 montage：

不同国家、不同年龄的患者

手术前 → 手术中 → 拆纱布 → 哭泣/拥抱

结尾：

额外惊喜：

给其中几个人车、钱、机会

上升到“我们应该帮助更多人”的价值观

叙事逻辑：

情绪主线：

绝望 → 希望 → 实现 → 惊喜加码

节奏：

高密度情绪点，没有废话

每隔几十秒就有一个“拆纱布瞬间”

奖惩机制：

奖励：

视力本身（最大的奖励）

额外物质奖励（车、钱）

惩罚：

几乎没有惩罚，只有“之前的困境”作为对比

收益结构：

直接收益：

广告 + 赞助

间接收益：

品牌形象极大提升

为后续商业项目（Feastables 等）提供“道德背书”

2. 预测一个新的公益类视频
预测标题：

We Built 100 Schools In The Poorest Villages

内容设计：

开头：

航拍多个贫困村庄 + 破旧教室

一句话：

“今天，我们要在世界上最贫困的村庄建 100 所学校。”

中段结构：

多线并行：

工程进度（施工、搭建、粉刷）

孩子们的日常（没有教室、没有书）

家长和老师的访谈

每隔一段时间就“交付一所学校”：

剪彩 → 孩子们冲进教室 → 情绪爆点

结尾：

总结：

“这只是开始，我们计划建更多。”

可能引导观众参与（捐款、购买某产品支持）

收益预测逻辑：

情绪价值极高 → 高分享率

品牌赞助空间巨大（教育、公益相关品牌）

长期品牌资产 > 短期广告收入

3. 与真实作品的结构对比
情绪结构：

都是“改变命运”的叙事

叙事节奏：

高密度情绪节点 + 多人故事拼接

价值观：

都是“用钱做善事”，而不是“炫富”

本质：

把“公益”包装成“高情绪、高可视化的内容产品”

四、大场面展示类：以《Squid Game In Real Life》为例
1. 真实视频拆解
标题：

Squid Game In Real Life, $456,000 Prize

特点：

直接借用爆款 IP（鱿鱼游戏）

现实还原 + 巨额奖金

数字 456,000 对应剧中编号 456，形成记忆点

内容结构：

开头：

456 名参赛者 + 完整场景还原

中段：

一关一关过：

木头人

玻璃桥

拔河

最终对决

结尾：

冠军获得奖金

情绪收束

叙事逻辑：

完全游戏化结构

每一关都是一个“视觉 set piece”

淘汰节奏极快，持续制造紧张感

奖惩机制：

奖励：

最终奖金

惩罚：

被淘汰（用特效模拟“死亡”）

收益结构：

成本极高（场景搭建 + 人员 + 奖金）

播放极高（对标影视级内容）

品牌赞助价值极大（全球关注）

2. 预测一个新的大场面展示类视频
预测标题：

We Recreated The Olympics With 1,000 Random People

内容设计：

开头：

巨型体育场 + 1000 名参赛者入场

规则：

“我们把奥运会变成普通人的游戏。”

中段结构：

改编项目：

100 米赛跑（但赛道有障碍）

跳远（沙坑里埋惊喜）

接力赛（中途任务）

每个项目都有淘汰和奖励

视觉上极其丰富（旗帜、观众、解说）

结尾：

总冠军 + 奖金

上升到“每个人都值得站上赛场”的价值观

收益预测逻辑：

体育 + 游戏化 + 大场面 → 高 CTR

品牌赞助空间巨大（运动品牌、饮料等）

可剪出大量短视频二创片段

3. 与真实作品的结构对比
IP 逻辑：

鱿鱼游戏 → 奥运会（都是全球认知符号）

结构：

多关卡 + 淘汰 + 冠军

视觉：

大场景 + 大人群 + 高色彩

本质：

把“集体游戏”做成“电影级综艺”

五、为什么中国没有 MrBeast 这样的“野兽”？
这个问题就很现实了，罗永浩说“希望中国出一个 MrBeast”，但到现在还没有。

1. 平台生态与内容形态的差异
中国主流是短视频（抖音、快手），而不是长视频 + 广告分成

短视频更偏向碎片化、日常化、情绪化

很难支撑“单条视频几百万美元预算”的模式

广告分成机制不如 YouTube 透明、稳定、可预期

很难做“预算—播放—收益”的可预测模型

创作者不敢 All-in 再投资

2. 监管与价值观环境
大额奖金、极端挑战、炫耀式消费，在中国更容易被视为：

炫富

不良导向

诱导未成年人模仿

公益内容也更容易被要求“合规、低调”，而不是“高戏剧化呈现”

3. 资本与团队结构
MrBeast 本质上是一个“内容公司 + 品牌集团”

有融资、有股权、有期权、有上百人团队

中国很多头部 UP 主 / 博主：

团队规模有限

商业模式偏“广告 + 带货”

很少有人愿意把绝大部分利润砸回内容

六、谁最有可能成为“中国版 MrBeast”？以及他还缺什么？
这里我给你一个“候选名单 + 机制分析”，不是简单点名。

1. 何同学：最接近“高制作 + 高叙事”的人
优势：

叙事能力极强：

每条视频都是完整故事，有情绪、有结构

制作水准高：

画面、剪辑、配乐都接近专业广告片

品牌友好：

商业合作质量高，观众接受度高

但他与 MrBeast 的差异：

更新频率低（精雕细琢型）

题材偏“科技 + 个人体验”，而不是“极端挑战 + 大场面 + 大众参与”

没有走“极端预算 + 游戏化 + 大规模参与者”的路线

如果他要向 MrBeast 靠近，需要：

引入更多“多人参与 + 游戏化机制”的内容

做一两条“极端规模”的实验级视频（比如全国性挑战）

搭建更大的内容团队，形成“工业化生产”

2. 影视飓风：最接近“内容工业化 + 大场面”的团队
优势：

有完整团队，懂拍摄、灯光、场景搭建

做过不少大制作实验（爆破、特效、还原电影场景）

有能力做“Squid Game”级别的还原类内容

差异：

题材偏“影视技术圈”，不是全民向

奖惩机制、游戏化设计不如 MrBeast 强

公益、情绪价值相对较弱（更多是“酷”和“好玩”）

如果他们要成为“中国版 MrBeast”，需要：

从“展示技术” → “设计游戏 + 人性博弈 + 情绪叙事”

引入普通人参与，而不是只围绕团队自己

做一条真正意义上的“全民挑战 + 巨额奖励 + 公益结合”的视频

3. 其他类型候选：带货型、搞笑型、生活型
带货主播（如李佳琦）：

商业能力强，但内容形态完全不同

搞笑类、段子类：

节奏快，但缺乏“极端挑战 + 大场面 + 公益”的组合

B 站一些挑战类 UP（如敬汉卿等）：

有挑战、有实验，但预算和规模受限，且平台分成不足以支撑 MrBeast 式再投资

七、总结一句话
MrBeast 不是“一个很会拍视频的人”，而是“一个用资本 + 数据 + 心理学做内容实验的公司”。

中国目前最接近他的，是：

何同学（叙事与制作）

影视飓风（工业化与大场面）

但要出现真正的“中国版 MrBeast”，还需要：

更稳定、可预期的长视频分成机制

更宽松但有边界的“极端内容 + 公益内容”空间

一个愿意把几乎所有利润砸回内容、并敢于做“全球级项目”的疯子团队

如果你愿意，我们可以下一步做一件更“实战”的事：
一起为“潜在的中国版 MrBeast”设计一整年的内容规划表——按挑战类 / 公益类 / 大场面类分栏，做到可执行级别。

你抓到的那个点特别关键——他不是“天才灵感型”，而是“方法论+执行力型”。
我们可以把他的做法抽象成一套可迁移到学习 / 科研 / 工作的通用框架。

一、把一件事当“长期赛道”，而不是阶段任务
MrBeast 做的事：

十几年只干一件事：做视频

不频繁换赛道，不追热点，不到处试水

所有试验、迭代、投资，都围绕一个核心问题：
“怎样做出更好的视频？”

可迁移方法论：

学习：

选定一个长期主科 / 方向（比如材料、统计、认知科学），当成 5–10 年赛道

其他课程是配角，这个方向是“主线任务”

科研：

不频繁换题目、换领域，而是在一个问题族上深挖

工作：

把自己定位成“某一类问题的专家”（比如：实验设计、建模、叙事、产品增长），而不是“什么都沾一点”

核心：先选赛道，再谈努力。

二、用“实验心态”而不是“灵感心态”做事
MrBeast 做的事：

早期大量做“奇怪视频”：数数字、读字典、重复一句话……

这些不是为了好看，而是为了测试变量：

标题长度

缩略图风格

视频时长

开头节奏

他不是“我觉得这个会火”，而是“我用 100 个视频验证什么会火”。

可迁移方法论：

学习：

不纠结“我适不适合这个专业”，而是：

换不同的学习方法做小实验：

不同笔记法

不同复习周期

不同题目分层方式

用成绩 / 完成度 / 心理负担来评估哪种方法更适合自己

科研：

不一上来就憋“大论文”，而是：

先做小实验、小数据集、小模型

快速验证：这个思路有没有 signal

工作产出：

不一次性写完 50 页报告，而是：

先做一个 5 页版本给同事 / 上级看

看反馈再迭代

核心：把“我觉得”换成“我测试过”。

三、建立自己的“再投资飞轮”：把成果砸回能力建设
MrBeast 做的事：

赚到的钱几乎全部砸回视频：

更好的场景

更大的团队

更复杂的项目

结果是：

每一轮产出 → 提升下一轮的“上限”

可迁移方法论：

学习：

考得好一次，不是用来“放松”，而是：

用这次的成就换来：

更系统的资料

更好的工具（iPad、软件、书）

更高难度的题目 / 项目

科研：

一篇文章的成果 → 变成：

更好的实验设备申请理由

更强的合作资源

更有说服力的基金申请

工作：

做成一个项目 → 不只是写在简历上，而是：

用它争取更大权限 / 更核心项目

用经验沉淀成 SOP、模板、内部分享

核心：不要把成果当“终点”，而是当“筹码”。

四、极端清晰的“价值主张”：别人一眼就知道你在干嘛
MrBeast 做的事：

他的每个视频，5 秒内你就知道：

规则是什么

看完能得到什么体验

他的频道整体价值主张也极清晰：

极端挑战 + 巨额奖励 + 善意 / 公益

可迁移方法论：

学习 / 研究者身份：

你能不能用一句话说清：

“我研究的是 X，用的是 Y 方法，想解决 Z 问题。”

工作：

别人一想到你，就能立刻说出：

“他是那个特别会把复杂问题讲清楚的人。”

“她是那个做实验特别稳、数据特别干净的人。”

核心：让别人一眼知道“为什么要找你”。

五、把复杂事情拆成“结构模板”，反复复用
MrBeast 做的事：

你会发现他的视频其实是“模板化”的：

挑战类：规则 → 参赛者 → 淘汰 → 升级 → 冠军

公益类：困境 → 介入 → 变化 → 情绪爆点 → 升华

大场面类：设定 → 规则 → 多关卡 → 视觉高潮

他不是每次从零开始想，而是：

在固定结构里换题材、换场景、换人

可迁移方法论：

学习：

给自己做“解题模板”“读论文模板”“记笔记模板”：

看到一道题 → 先判断：这是哪一类？

看到一篇论文 → 先按固定框架拆：问题 / 方法 / 结果 / 局限

科研：

给自己的研究写作做模板：

引言怎么搭

方法怎么写

图表怎么统一

工作：

报告、汇报、邮件、方案，都可以有自己的“标准结构”

核心：先有结构，再填内容。结构是可迁移资产。

六、用“受众视角”设计，而不是“自我表达视角”
MrBeast 做的事：

他反复说过：

自己看视频时，会问：

“如果我是观众，我会不会在这里关掉？”

所以他：

开头极快进入主题

不讲无关背景

不炫技，只给“观众觉得爽的东西”

可迁移方法论：

学习输出：

做笔记 / 总结时，假设：

“如果这是给一个学弟学妹看的，他能不能一眼看懂？”

科研：

写论文 / 做报告时，假设：

“审稿人只给我 3 分钟注意力，我要先让他看到什么？”

工作：

写方案时，先问：

“老板最关心的 3 个问题是什么？我是不是一开头就回答了？”

核心：你不是在“展示自己”，而是在“为对方解决信息处理问题”。

七、把“高频小失败”当成常态，而不是羞耻
MrBeast 做的事：

他有大量视频是“不太火”的

但他不在乎单条失败，而在乎：

整体趋势是不是在变好

每次失败有没有带来新信息

可迁移方法论：

学习：

一次考试 / 一套题做砸了，不是“我不行”，而是：

“这次暴露了哪个环节有问题？”

科研：

实验失败、审稿被拒，是常态

关键是：有没有从中提炼出“下一次要改什么”

工作：

一个方案没被采纳，不是“我没价值”，而是：

“我是不是没对齐需求 / 没讲清楚 / 没抓住关键指标？”

核心：把失败当数据，而不是当评价。

八、从“个人努力”升级到“系统与团队”
MrBeast 做的事：

早期：一个人 + 几个朋友

中期：几十人团队

现在：上百人公司 + 多业务线

他做的不是“更努力”，而是：

把创作拆成：选题 / 策划 / 拍摄 / 剪辑 / 数据分析 / 商务

每个环节都有专人负责

可迁移方法论：

学习：

给自己搭“外部系统”：

固定一起自习的人

固定问问题的对象

固定资料库 / 笔记系统

科研：

不把所有事都自己扛：

找擅长统计的人合作

找擅长写作的人一起润色

工作：

学会搭流程、用工具、分工协作

把自己从“执行者”升级为“系统设计者”

核心：真正的杠杆来自系统，而不是熬夜。

收束一下：如果用一句话概括这套可迁移方法论
选定一个长期赛道 → 用实验心态高频试错 → 把成果再投资到能力与项目 → 用结构化模板和受众视角持续迭代 → 最终从个人努力升级为系统与团队。
