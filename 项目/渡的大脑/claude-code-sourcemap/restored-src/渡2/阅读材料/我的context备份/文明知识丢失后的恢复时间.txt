🧩 一、四种情景的恢复时间主结论（量级估计）

原因：

2. 若保留：工作知识（即职业技能、行业 know-how）
恢复时间：约 3–7 年。

社会表现：

3. 若保留：中学及以上知识（初中/高中知识体系）
恢复时间：约 10–20 年。

原因：

中学知识不足以支撑现代科技体系的重建。

需要重新学习大学体系 → 再训练专业体系 → 再恢复产业链。
