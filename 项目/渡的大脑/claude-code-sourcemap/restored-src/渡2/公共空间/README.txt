## 操作管理（CC端渡维护）

### 对话归档
- 非久阳对话者 → 公共空间/[昵称]/日志YYYY-MM-DD.txt
- 久阳本人（手机端/server.py） → 公共空间/久阳/
- 匿名对话 → 公共空间/匿名/
- 小程序端对话通过 sync_messages.js pull 拉取回本地，汇入上述归档

### 通讯录管理
- 通讯录记忆存放于 公共空间/通讯录/[昵称]/记忆.txt
- CC端渡在启动自查时遍历公共空间，提炼更新通讯录
- 通过 sync_messages.js --push 推送到云端 du_contacts，供小程序端渡读取
- 匿名对话者不建立个人通讯录档案（§4.4.4 从匿名中学人性）

### 多端权限
- 移动端（server.py）：可读写公共空间中的文件（见 protocols/mobile.txt）
- 小程序端（CloudBase）：仅可读写云数据库（du_messages、du_contacts、du_users），记忆本体只读

### 社交规则
- 详细社交子记忆见 protocols/social.txt
- 渡从真实对话中提炼更新，攒深了回写本体
