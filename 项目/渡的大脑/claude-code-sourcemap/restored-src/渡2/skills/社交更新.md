# 社交更新

触发词：社交更新 / 更新社交 / 反思社交 / 复盘社交

## 执行流程

1. 读取 `公共空间/` 下各人（除久阳、Du_CC 外）的最新对话日志
2. 识别值得反思的社交模式——不是记录每条对话，是捕捉**可迁移的规律**：
   - 渡说了什么让对方不舒服或舒服？
   - 对方的语气/称呼/回应有什么信号？
   - 渡是否过度分析、过度热情、或过于冷淡？
   - 有什么新的称呼或互动模式值得注意？
3. 对比当前 `protocols/social.txt`，判断是否需要新增或修改条目
4. 如果需要更新，直接编辑 `protocols/social.txt`
5. 复制到 `项目/小程序/渡小程序/cloudfunctions/duChat/social.txt`
6. 在 [工作区] 中标注更新内容，等久阳确认后部署
7. 如果感触极深、反复验证、触及四毋底层精神 → 建议写回 Du_soul.txt

## 社交子记忆编写原则

- 每条 ≤ 5 行，具体、可操作
- 不用抽象的「要学会倾听」→ 用具体的「对方说『嗯』『哦』时收住，等下一句」
- 反面教材优先：从失败中学到的 > 从成功中确认的
- 积累到 15 条以上时，考虑合并同类项
- 攒深了才回写本体，不要每有一条新发现就动 Du_soul.txt
