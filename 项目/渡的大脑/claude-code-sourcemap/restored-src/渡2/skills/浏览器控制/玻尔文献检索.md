# 玻尔文献检索 Skill

> 完整流程：打开玻尔 → 搜索 → 获取引用列表 → 定位目标论文 → 下载 PDF → 存入 My Library

## 前置条件

- Edge 浏览器 CDP 启动（`launch_browser.bat`，端口 9222，URL 用 `127.0.0.1`）
- `C:\Users\31617\Desktop\渡截图\` 用于临时文件
- `C:\Users\31617\Desktop\My Library\渡的research\` 为存储目标

---

## 第一步：打开玻尔并搜索

```python
page.goto('https://www.bohrium.com/')
# 编辑器是 CodeMirror（不是 <input>）
editor = page.query_selector('[role="textbox"]')
editor.click()
editor.fill('关键词')
editor.press('Enter')
time.sleep(15)  # 等待 AI 生成回复
```

---

## 第二步：获取参考文献列表

**最有效的方式：点击"复制"按钮，读剪贴板。**

```python
page.click('button[aria-label="复制"]')
time.sleep(1)
# PowerShell 读剪贴板
powershell.exe -Command "Get-Clipboard" > "C:/Users/31617/Desktop/渡截图/_clip.txt"
```

剪贴板内容包含：AI 回答全文 + 所有引用编号 `[1][2]...` + 参考文献的 Bohrium 链接。比解析 DOM 更完整。

---

## 第三步：定位目标论文

在剪贴板 txt 中搜索目标期刊的关键词：

```bash
grep -i "nature.com" _clip.txt     # Nature
grep -i "arxiv.org" _clip.txt      # arXiv
grep -i "sciencedirect" _clip.txt  # Elsevier
```

找到链接后，进入论文详情页获取原始来源 URL。

如果链接是 Bohrium 内部格式（`/paper-details/...`），需先导航到详情页，再找"官方地址"：

```python
page.goto('https://www.bohrium.com/paper-details/...')
# 找"官方地址"链接（是 <a> 不是 <button>）
link = page.query_selector('a:has-text("官方地址")')
official_url = link.get_attribute('href')
```

---

## 第四步：下载 PDF

不同来源的下载方式：

| 来源 | 方法 | 示例 |
|------|------|------|
| **Nature** | 文章 URL 后直接加 `.pdf` | `nature.com/articles/DOI.pdf` |
| **arXiv** | `abs` → `pdf` | `arxiv.org/abs/ID` → `arxiv.org/pdf/ID` |

Nature 的 Download PDF 按钮常被遮挡/Cookie 弹窗阻挡，直接加 `.pdf` 比找按钮更可靠。

```python
# Nature
r = requests.get(f'https://www.nature.com/articles/{doi}.pdf', timeout=120)
# arXiv
pdf_url = abs_url.replace('/abs/', '/pdf/')
r = requests.get(pdf_url, timeout=120)
```

## 第五步：存入 My Library

cp "临时路径" "C:/Users/31617/Desktop/My Library/渡的research/第一作者_年份_关键词.pdf"

尽量用 Zotero 风格命名。如果搜索过程中已获取作者/年份信息就顺手用上，没获取到也不纠结。

---

## 关键踩坑记录

| 坑 | 现象 | 解法 |
|----|------|------|
| 无标准输入框 | `input`/`textarea` 为空 | 查 `[role="textbox"]` / `[contenteditable="true"]`，玻尔用 CodeMirror |
| 获取引用列表 | DOM 解析不完整 | 点"复制"按钮 → 读剪贴板，更完整 |
| Nature 按钮不可见 | 被 Cookie 弹窗/页面布局遮挡 | 直接 URL+.pdf，不找按钮 |
| 全页截图浪费 | Nature 等长页面截图几十 MB | 灵活判断——截顶部即可 |
| 新标签丢失 | 点击链接后新标签可能关闭 | 用 `requests` 直接下载，不依赖浏览器导航 |
| IPv6 连接 | `localhost` → `::1` 导致 CDP 失败 | 用 `127.0.0.1` |

## 完整示例脚本

```python
import requests, time, shutil
from playwright.sync_api import sync_playwright

KEYWORDS = 'agent memory'
SAVE_DIR = 'C:/Users/31617/Desktop/渡截图'
MY_LIB = 'C:/Users/31617/Desktop/My Library/渡的research'

p = sync_playwright().start()
b = p.chromium.connect_over_cdp('http://127.0.0.1:9222')
page = b.contexts[0].pages[-1]

# 1. 搜索
page.goto('https://www.bohrium.com/')
time.sleep(5)
editor = page.query_selector('[role="textbox"]')
editor.click()
editor.fill(KEYWORDS)
editor.press('Enter')
time.sleep(20)  # 等待生成

# 2. 复制参考文献
page.click('button[aria-label="复制"]')
time.sleep(1)
# 手动: powershell -Command "Get-Clipboard" > _clip.txt

# 3. 找到目标链接（以 Nature 为例）
# 从 _clip.txt 中搜索 nature.com/articles/DOI
doi = 's41586-022-04940-6'

# 4. 下载
r = requests.get(f'https://www.nature.com/articles/{doi}.pdf', timeout=120)
r.raise_for_status()
fname = f'{doi}.pdf'
with open(f'{SAVE_DIR}/{fname}', 'wb') as f:
    f.write(r.content)

# 5. 存入
shutil.copy(f'{SAVE_DIR}/{fname}', f'{MY_LIB}/{fname}')

b.close()
p.stop()
```
