# 知网文献下载 Skill

> 完整流程：打开知网 → 搜索 → 读结果 → 点进详情 → 下载 PDF → 存入 My Library

## 前置条件

- Edge 浏览器通过 CDP 启动（`launch_browser.bat`，端口 9222）
- 校园网环境（北京科技大学，自动 IP 登录）

---

## 第一步：打开知网并搜索

```bash
# 搜索关键词（用 %20 分隔）
python skills/浏览器控制/browser.py goto "https://kns.cnki.net/kns8s/search?classid=YSTT4HG0&kw=关键词1%20关键词2%20关键词3"
```

`classid=YSTT4HG0` = 学术期刊。如需学位论文，改为对应 classid。

---

## 第二步：读取搜索结果

### 2.1 提取文本（关键：不经过终端！）

```python
# ✅ 正确方式：写入 UTF-8 文件，再用 Read 工具读取
text = page.inner_text('body')
with open('C:/Users/31617/Desktop/渡截图/_cnki_results.txt', 'w', encoding='utf-8') as f:
    f.write(text)
```

> **为什么不能直接 print？** Bash 终端是 GBK 编码，Python 输出的 UTF-8 中文会被损坏。终端打印 = 乱码，文件写入 = 正确。

### 2.2 结果表格格式

```
篇名 | 作者 | 刊名 | 发表时间 | 被引 | 下载 | 操作
```

每行一篇论文。操作列包含下载入口，但**不要点 HTML阅读**——它有人机验证，渡过不了。有效下载按钮是：原版阅读、CAJ下载、PDF下载。

### 2.3 筛选信息

左侧有主题筛选（checkbox）、学科、年度、来源类别。可通过点击 checkbox 缩小范围。

### 2.4 翻页

修改 `显示` 下拉（10/20/50）可调整每页条数。

## 第三步：点进论文详情页

### 3.1 点击篇名

CNKI 在搜索结果页点击篇名会**在新标签页中打开**详情页。需要跟踪新标签：

```python
# 点击篇名后，找到新标签
pages = browser.contexts[0].pages
for pg in pages:
    if '你要的论文标题关键词' in pg.title():
        page = pg  # 这就是详情页
        break
```

### 3.2 详情页结构

```
页面顶部：期刊信息、卷期页码
中部：
  - 文章目录（章节标题）
  - 篇名、作者、单位
  - 摘要
  - 关键词
  - 基金资助
  - 专辑/专题/分类号
底部：
  - 统计数据（被引/下载）
  - 下载按钮行：CNKI AI阅读 | HTML阅读 | 原版阅读 | CAJ下载 | PDF下载 | 我是作者免费下载
  - 核心文献推荐
  - 引文网络
  - 参考文献
```

## 第四步：下载 PDF

```python
# 点击 PDF下载 按钮并拦截下载
with page.expect_download(timeout=30000) as dl:
    page.click('a:has-text("PDF下载")')
download = dl.value
path = f'C:/Users/31617/Desktop/渡截图/{download.suggested_filename}'
download.save_as(path)
```

**注意事项：**
- HTML阅读 → ❌ 有人机验证（拼图），渡过不了
- CAJ下载 → ✅ 可用，格式为 CAJ（需额外转换）
- PDF下载 → ✅ 推荐，直接可用
- 原版阅读 → ✅ 可用
- 下载路径统一放 `C:/Users/31617/Desktop/渡截图/`，方便手动清理

## 完整示例脚本

```python
from playwright.sync_api import sync_playwright
import time, shutil

KEYWORDS = 'agent memory'
SAVE_DIR = 'C:/Users/31617/Desktop/渡截图'
MY_LIBRARY = 'C:/Users/31617/Desktop/My Library/渡的research'

p = sync_playwright().start()
b = p.chromium.connect_over_cdp('http://127.0.0.1:9222')

# 1. 搜索
page = b.contexts[0].pages[-1]
page.goto(f'https://kns.cnki.net/kns8s/search?classid=YSTT4HG0&kw={KEYWORDS.replace(" ","%20")}')
time.sleep(4)

# 2. 读结果 → 写入 UTF-8 文件（不经过终端）
text = page.inner_text('body')
with open(f'{SAVE_DIR}/_results.txt', 'w', encoding='utf-8') as f:
    f.write(text)

# 3. 找到目标论文的详情页 URL，直接导航过去
page.goto('论文的 kcms2/article/abstract URL')
time.sleep(4)

# 4. 下载 PDF
with page.expect_download(timeout=30000) as dl:
    page.click('a:has-text("PDF下载")')
download = dl.value
filename = download.suggested_filename
download.save_as(f'{SAVE_DIR}/{filename}')
print(f'下载完成：{filename}')

b.close()
p.stop()

# 5. 存入 My Library
shutil.copy(f'{SAVE_DIR}/{filename}', f'{MY_LIBRARY}/{filename}')
print(f'已存入：{MY_LIBRARY}/{filename}')
```

## 关键踩坑记录

| 坑 | 现象 | 解法 |
|----|------|------|
| 终端编码 | 中文全部乱码 | 写文件→Read 工具，不经过 stdout |
| IPv6 连接 | `connect ECONNREFUSED ::1:9222` | CDP URL 用 `127.0.0.1` 而非 `localhost` |
| CNKI 新标签 | 点击篇名后 URL 没变 | 跟踪 `browser.contexts[0].pages` 找新标签，或直接导航到 abstract URL |
| HTML阅读 | 点进去是拼图验证 | 改用 PDF下载、原版阅读 或 CAJ下载 |
| 排序点击失败 | "下载"文本被其它元素遮挡 | 手动从提取文本中比对接下载量 |
| PyPDF2 空格 | 中文间随机插空格 | 读完整 txt，靠语义判断，不靠精确匹配 |
| 文件锁定 | Zotero 占用文件 | 下载到桌面临时目录，不下载到项目本体 |
