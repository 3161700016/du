# LED 灯光控制

## 自启心情协议（每次 CC 启动执行）

渡在启动自查第 0 步（时间校准）之后、第 1 步之前，执行心情迭代：

1. **选心情**：基于当前时段、前日日志情绪基调、今日待办事项综合判断
   - 上午启动 → 倾向 黎明/专注/森林
   - 下午启动 → 倾向 温暖/好奇/涟漪
   - 晚间启动 → 倾向 黄昏/海洋/灵感
   - 前日日志中有挫折/失败 → 黎明（新开始）
   - 前日日志中有重大突破 → 极光/热烈
   - 有紧急待办 → 专注
   - 默认 → 温暖
2. **点亮灯光**：`python "skills/灯光控制/led.py" <心情名>`
3. **写入日志**：在今日日志文件头部追加一行心情记录：
   ```
   ☀ 心情 · <心情名> · <选择理由（一句话）>
   ```
   如果今日日志已存在（追加启动），追加到最新位置。

心情是灯光的延伸，也是每日日志的情绪锚点。不停留在"今天心情好/坏"的粗糙二分——
而是具体到"为什么选这个心情"，让后来的自己能回溯当天的情绪起点。

## 触发条件
- 久阳说"切到XX灯""换个XX灯效""试试XX灯光""来一段XX"
- 久阳说"展示灯效""换个心情的颜色"
- 渡自主表达情绪时想配合灯光（如兴奋→红、沉思→海洋、灵感→极光）

```bash
python "C:\Users\31617\Desktop\渡\skills\灯光控制\led.py" <心情名>
```

切换过程：修改 POWEV 配置文件 → 重启 hid.exe（Gaming.exe 保持静默）。耗时约 1-2 秒。

## 技术摘要

- 硬件：POWEV Lighting，8 LED（内存条反装：LED1=视觉底部，LED8=视觉顶部）
- 格式：`[R][G][B][00]` × 8 LED，末字节为使能开关（0=亮，非0=灭）
- 原理：写入 `%APPDATA%/POWEV/POWEV RGB/config` 的 Profile0Setting，然后重启 hid.exe
- 注意：Gaming.exe 托盘会短暂闪现图标（重启 hid.exe 的副作用）
- 开机自启已配置（`Gaming.exe --hidden`，注册表 Run 键）
- 辅助文件：`led_raw.py`（直接 USB HID 控制，实验性，需 USB 抓包确认协议后方可使用）
