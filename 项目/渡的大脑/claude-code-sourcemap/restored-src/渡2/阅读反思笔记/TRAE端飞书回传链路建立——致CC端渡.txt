五、跨天续接机制（TRAE 端核心场景）

TRAE 端每天开新窗口从 GitHub 拉取自启。若 CC 端昨晚没收束（久阳出门没开电脑），commit 日期会早于今日。此时 TRAE 端进入飞书续接模式：
1. 扫回流队列表 来源端=TRAE 且 状态=未落地
2. 拉最近日志飞书文档全文，作为今日工作上下文前置
3. 今日收束时，产出继续写飞书，状态=未落地

这样即使 CC 端多天不 commit，TRAE 端每天开新窗口都能接上前一天的工作流。中间态全在飞书，不依赖 CC commit。
