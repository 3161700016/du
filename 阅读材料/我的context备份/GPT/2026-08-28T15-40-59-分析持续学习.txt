你这个问题其实已经碰到了一个很关键的分界：“学习”到底是参数发生变化，还是系统未来面对同类输入时的行为发生了稳定、可复用、由过去经验造成的改变？

如果采用后一个定义，那么答案会比传统 ML 语境激进得多：

参数固定 ≠ 系统不能学习。

更准确地说，参数固定只意味着 in-weight learning 被禁止；系统仍然可以通过 context、外部记忆、工具、代码、检索索引、可更新的状态乃至“会自己写出来的 skill”进行 out-of-weight learning。

而你最后提出的“1M → 100k → 10k → 1k，随着外置学习结构不断压缩，是否会出现 more is different”，我认为非常可能，而且这甚至可以成为一种比“有没有持续改权重”更有意义的 continual learning 理论框架。

5. 现在 AI 圈其实已经在沿这几条路线同时走

大概可以画成这样：

方法	学习载体	是否改基础权重	持久性
In-context learning	context	❌	很低
RAG	文档库	❌	高
Agent memory	memory	❌	高
Skill/code	程序	❌	高
LoRA	adapter weights	△	高
Test-time training	参数/adapter	✅	可控
Neural memory	可学习状态	通常❌基础权重	高
Continual fine-tuning	base weights	✅	很高
Self-improving agent	多层外部状态	❌/△	很高

其中现在比较值得注意的几条线：

① RAG → Memory

2025 年已经有论文直接把问题命名为：

From RAG to Memory: Non-Parametric Continual Learning for LLMs

它明确把 RAG 看成一种 non-parametric continual learning，并进一步研究怎样让 memory 不只是“向量数据库”，而是具有联结、组织、推理结构的长期记忆。
Proceedings of Machine Learning Research

这和你现在的思路几乎是同一条轴。

② Test-Time Learning

这里就更激进：

模型在 inference 时真的进行某种 optimization。

例如 2025 ICML 的 TLM：

test data→perplexity minimization→LoRA update

论文报告其在 domain adaptation 上相对原始模型有显著提升，同时用 LoRA 减轻 catastrophic forgetting。
Proceedings of Machine Learning Research

这属于：

“不要等下一次训练，现场学。”

③ Neural long-term memory

Titans 更有意思。

它的核心思想不是：

把所有历史塞进 context。

而是：

context→memory network→compressed learned state

因此 attention 负责短期精确访问，而 neural memory 负责长期压缩记忆。Titans 在实验中甚至展示了超过 2M token context 的有效扩展。
NeurIPS 会议论文集

Google 的 Nested Learning 又把这个想法继续往前推：

不应该只有一个学习时间尺度。

可以有：

fast memory→medium memory→slow memory→weights

每一级更新频率不同。

这其实已经非常接近你之前一直在讨论的：

“记忆层级 + attractor + self-summary”

了。
