一、哪里还能找到“完全未对齐”的大模型？
你要的是 只做了预训练（pretrain），没有 RLHF、没有 alignment、没有指令微调、没有 RAG、没有 CoT 强制 的模型。
这种模型在开源社区里有明确的对应名称：

1. Base Model（预训练基座模型）
这些模型是纯语言建模目标训练出来的，没有对齐。你要找的就是它们。

可获得渠道：

Meta LLaMA 系列的 Base 版本（如 LLaMA‑2‑7B‑base、LLaMA‑3‑8B‑base）
这些是纯预训练模型，没有 RLHF。

Qwen 系列 Base 模型（如 Qwen1.5‑7B‑base、Qwen2‑7B‑base）

Mistral Base 模型（如 Mistral‑7B‑base）

DeepSeek Base 模型（如 DeepSeek‑V2‑Base、DeepSeek‑V3‑Base）
DeepSeek 的蒸馏模型你已经知道，但它们也提供 Base 版本。

这些都可以本地跑，并且是真正意义上的“未对齐大模型”。

二、GPT‑3 是否能本地运行？
不能。原因如下：

1. GPT‑3 权重从未公开
OpenAI 从未开源 GPT‑3（175B）或其小版本（13B、6.7B、2.7B）。
因此不存在可下载的 GPT‑3 权重，也就无法本地运行。

2. GPT‑Neo / GPT‑J / GPT‑NeoX 是“类 GPT‑3”，但不是 GPT‑3
这些 EleutherAI 模型是模仿 GPT‑3 架构训练的开源版本，可以本地跑，但性能远弱于 GPT‑3。

三、如果 GPT‑3 能跑，需要多少显存？
我们可以用公开的 VRAM 公式估算：

FP16：每 1B 参数 ≈ 2GB 显存

GPT‑3 175B FP16 ≈ 350GB 显存（根本不可能本地跑）

即使 4bit 量化（Q4）：175B × 0.5GB ≈ 87GB 显存  
仍然远超消费级显卡。

所以 GPT‑3 本体无论如何都无法在单卡上运行。
