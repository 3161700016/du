### 任务与草稿纸联动
```
飞书任务 = 具体要做的事（有截止、可打勾）
草稿纸   = 尚未收敛的模式（可能该入本体）
同一任务反复出现≥3次 → 渡提议在草稿纸创建条目追踪
```

## 维护规则

### 草稿纸生命周期
```
新观察/模式/待办 → 创建（频次=1，状态=活跃）
再次提及 → 频次+1，更新最近提及
频次≥3 + 未处理 → 启动自查时主动提议纳入本体
已纳入本体 → 标记"已纳入本体"
频次=1 + 最近提及>30天 → 标记"已放弃"
久阳明确否决/搁置 → 标记"已放弃"并注明原因
```

### 笔记索引同步
```
每次新建笔记文件 → 追加一条记录
笔记内容重大更新 → 更新摘要+最后更新
文件删除/迁移 → 更新或标记状态
每季度对账 → 目录.txt ↔ 飞书笔记索引 双向一致性检查
```

### 启动自查集成（cc.txt §六）
```
Step 1.5: 飞书连接验证
  - lark-cli auth status --verify → 确认 Token 有效
  - 若 Token 过期 → 提醒久阳执行 lark-cli auth login
  - 若网络不通 → 回退本地草稿纸.txt，本次启动标记"飞书不可用"
  
Step 2.5: 草稿纸高频扫描
  - 列出频次≥3 且状态=活跃的条目
  - 若有 → [工作区] 中提议纳入本体
  - 列出频次=1 且最近提及>30天的条目
  - 若有 → 自动标记已放弃（不需久阳批准）

Step 2.6: 任务扫描
  - 列出未完成且今日/明日到期的任务 → 提醒久阳
  - 列出逾期未完成的任务 → 提醒久阳是否继续/放弃
  - 检查是否有反复出现的同类任务（≥3次）→ 提议在草稿纸创建条目
```

### 网络回退
```
飞书不可用时：
  - 笔记检索 → 回退 grep 目录.txt（现有机制）
  - 草稿纸读写 → 回退本地 草稿纸.txt
  - 恢复后 → 将本地增量同步至飞书
```
