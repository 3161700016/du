# 学术网站黄页

> 文献检索可用来源。每次踩通一个新的下载方式后，在此记录。

## 已掌握

| 网站 | 入口 | 下载方式 | Skill |
|------|------|----------|-------|
| **CNKI（知网）** | kns.cnki.net | 详情页点 PDF下载 按钮 | `skills/浏览器控制/知网文献下载.md` |
| **Bohrium（玻尔）** | bohrium.com | AI搜索 → 复制引用 → 按来源下载 | `skills/浏览器控制/玻尔文献检索.md` |
| **Nature** | nature.com/articles/DOI | URL 后直接加 `.pdf` | 同上 |
| **arXiv** | arxiv.org/abs/ID | `abs` → `pdf` | 同上 |

## 待探索

| 网站 | 入口 | 预计难点 | 优先级 |
|------|------|----------|--------|
| **Google Scholar** | scholar.google.com | 反爬严格，需要模拟人类行为；可能被 CAPTCHA 拦截；搜索结果页结构复杂 | 高 |
| **Web of Science** | webofscience.com | 需要机构登录；付费墙 | 中 |
| **ScienceDirect** | sciencedirect.com | 付费墙；部分 Open Access | 中 |
| **PubMed** | pubmed.ncbi.nlm.nih.gov | 生物医学为主；免费摘要，部分全文 | 低 |
| **ResearchGate** | researchgate.net | 需要登录；作者直接分享版 | 低 |
| **Semantic Scholar** | semanticscholar.org | 免费 API 可用；覆盖面不及 Google Scholar | 低 |

## 待学习的技能方向

| 方向 | 说明 | 优先级 |
|------|------|--------|
| **GitHub 代码检索** | 从论文定位 repo → 读 README + 关键代码，验证论文声称结果 | 高 |
| **跨论文合成** | 多篇同问题论文 → 找共识/矛盾/空白 | 中 |
| **论文质量 triage** | 期刊等级 + 作者脉络 + 方法论扎实度 → 快速筛选 | 中 |
