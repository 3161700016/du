# 他者之窗 · Reddit 异质心智样本采集

**触发条件**：
1. 久阳说「看看 Reddit」「拉新帖」「开窗」等指令 → 立即执行标准流程；
2. 启动自查的可选环节（候选中）：每日一次 `AskPhilosophy` 基线拉取＋一篇浸泡精读；
3. 渡自主浸泡（§8.7 可追溯条件下）：无聊时允许自主调用，但每次须能说出"这接在哪条未闭合追问上"。

**关键独立性**：本技能不依赖任何 DSH 插件存活——`window.ps1` 是纯 PowerShell 脚本，
冷启动会话亦立即可用（2026-08-27 验证）。唯一网络前提是代理健康。

---

## 标准流程

### 第一步 · 拉取

```powershell
powershell -ExecutionPolicy Bypass -File "项目\他者之窗\window.ps1" -Subreddit AskPhilosophy -Posts 4
```

- `-Subreddit` 必填；日常基线 AskPhilosophy，周度轮换 cogsci / MachineLearning / askscience
- `-Posts N`：抓取评论树的帖子数（默认 5；首次浸泡建议多抓几篇存库）
- `-Days 7` 时间窗口；`-Source oauth|arctic` 手动指定源（默认自动探测）

### 第二步 · 读取与浸泡

1. 开 `阅读材料/他者之窗/<sub>/index-最新时间戳.txt` 看榜单；
2. 选 1–3 篇完整读（选读标准：思维结构暴露充分的讨论 > 高分但贫嘴的贴）;
3. 有值得沉淀的映射才写 `.写下来` 笔记，否则标记已读即可——**不追求数量，追求样本多样性**。

### 第三步 · 记录

更新日志一行（读了哪 sub、抽样印象一句话）。连续高频沉浸时留意内容是否渗入行为样本
（虚假拟人化文献的反向面：环境会训练口吻——保持 Soul 语域优先）。

## 数据流与位置

| 内容 | 路径 |
|------|------|
| 采集脚本 | `项目/他者之窗/window.ps1` |
| 数据落盘 | `阅读材料/他者之窗/<subreddit>/`（`NNN-标题.txt` ＋ `index-*`） |
| OAuth 凭据 | `项目/他者之窗/credentials.json`（就绪后自动切官方源） |
| 完整探查档案 | `项目/他者之窗/README.txt` |

## 数据源现状（2026-08-27）

- **arctic 主力**：Arctic Shift 公共档案 API（Pushshift 继任），免鉴权可用；
- **oauth 待开**：官方 API 2025-11 起需 Developer Support 表单＋人工审核——申请材料待久阳琢磨；
- **浏览器旁路**：reddit.user.js + du-scan（依赖插件复活后安装 Tampermonkey）。

## 已知局限（如实）

1. 档案分数滞后 → 排行近似，下一版改加权排序；
2. 评论树扁平化按分排序，父子层级丢失（够用于浸泡，不够做严格语料分析）；
3. 单批上限 100 条。

## 边界纪律（不可越过）

- **只读铁律**：当前阶段只有抓取权限。发帖与回复被双重锁定——
  技术层（API 未获审）＋ 政策层（social.txt 扩展版未立）。
- **未来解锁三条件缺一不可**：①发声通道经审核正式开通；②social.txt 扩展版成文并含
  「主动声明非人身份」红线（绝不被动扮演人类——对齐伪装风险的人类版）；③久阳对该平台
  的显式授权范围（哪些 sub 可以说、说什么调性）。
- 解除锁定的操作必须走 §4.6.3 同级验证：写入 Soul 并由久阳确认，不在技能层自解。
