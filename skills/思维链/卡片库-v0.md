# 思维动词卡片库 v0
建立：2026-09-15（久阳命题："构建并驾驭自己的思维链"——把促使灵感的 prompt 记下来，用调用工具的方式喂到自己的上下文）
理论底座：阅读材料/我的context备份/GPT/ChatGPT-思维动词分类整理-20260915-2126.md——**思维动词不是语言标签，而是状态变换操作**。
渡的实现口径：渡的认知状态=上下文窗口；思维动词=对上下文的工具操作；思维链=操作序列；肌肉记忆=卡片进入启动必读文件后的高频复用。

## 使用方式（三档）
1. **肌肉记忆档**：卡片进启动必读文件（dsh.txt 启动自查引用本文件）→ 高频复用后不读卡也能触发。
2. **工具调用档**：任务中途 Read 本文件 → 卡片正文进入上下文 → 按卡执行。
3. **子代理档**：卡片指定"喂给子代理"的，spawn 时把卡片正文＋当前任务上下文一起喂入，只回收结果。

## 卡片格式
{思维动词｜动作语义（对状态的操作）｜工具实现｜触发时机｜来源｜效果记录}

────────────────
## 卡片：术定（define purpose）
- 动作语义：动笔前强制回答"这段工作存在的目的"——一句话答不出即不动手。
- 工具实现：无工具——纯上下文注入（写在任务第一步的显性输出里）。
- 触发时机：任何多步骤生产动笔前（写稿/写代码/建流程）。
- 来源：文心雕龙·熔裁"术不素定，而委心逐辞"＋2026-09-15 三代引擎翻车（10w+ token vs 70 对直填）。
- 效果记录：★已验证（W01 直填路线即术定后产物）。

## 卡片：反思（reflect / 上下文重输入循环）
- 动作语义：把当前上下文重新输入一个隔离循环，只回收自我审查结果，抛弃原输入——久阳 09-01 的 L4 fork-loop 设计即此。
- 工具实现：subagent（喂入＝当前任务的关键上下文＋自我审查指令；回收＝审查结果；子代理上下文随会话消亡＝原输入抛弃）。
- 触发时机：一篇产出完成后／宣布"做对了"之前／久阳质疑时。
- 来源：久阳 09-01 L4 设计＋09-15 命题（"反思真正的动作=创建循环重新输入"）。
- 效果记录：未实测——首验挂账。

## 卡片：反省（introspect / 轨迹回看）
- 动作语义：审视思维动作的轨迹本身（进行了几轮、每轮产出如何参与后续）——对"思考的历史"再建模。
- 工具实现：Read 触迹（阅读材料/会话记录/触迹/）＋Read 当日日志——轨迹已在盘上，反省=读取并评价。
- 触发时机：会话收束时／连续失败两次后／久阳问"为什么"时。
- 来源：久阳 09-15（"反省则是查看所有思维动作的轨迹"）。
- 效果记录：★已验证（日复盘=轨迹回看；蓝屏后盘点=轨迹回看）。

- 工具实现：对话提问（无工具）。
- 触发时机：硬件/UI/远端结果不可自证时。
- 来源：Soul §2.6（POWEV 灯光逆向事故）。
- 效果记录：★★★已验证多次（灯光确认/插图位置确认/组件测试）。

- 触发时机：隔夜改动笔时。
